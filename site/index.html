Method / evidence first

Observe less.
Explain more.

ForgeRank deliberately trades universal coverage for a bounded, reviewable pipeline. A rank always describes the repositories observed at that calculation time.

  1. 01Identify

    Validated public identifiers enter a deduplicated queue.

  2. 02Observe

    Public pages that pass the current exact-URL robots rules and bounded HTTPS Git reads provide evidence.

  3. 03Preserve

    Append-only snapshots retain time, parser, source hash, and confidence.

  4. 04Explain

    Versioned formulas persist one reason per score dimension.

Credential boundary

No REST, GraphQL, token, OAuth, or hidden endpoint.

Collection is cached, budgeted, and stopped on robots denial, throttling, or uncertainty. Avoiding API credentials does not mean unlimited access or complete GitHub coverage.

Coverage truth

A real fresh install begins with identifiers, not analytics. Rankings cover ForgeRank’s observed corpus—not every repository on GitHub. Blocked, stale, or insufficient evidence is shown as unavailable instead of estimated.
