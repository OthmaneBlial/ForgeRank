Method / evidence first

Evidence in.
Reasons out.

ForgeRank separates acquisition, observation, inference, and presentation. Scores are versioned; source provenance is retained; missing inputs contribute nothing.

  1. 01 Identify

    Curated identifiers and validated public submissions enter a deduplicated queue.

  2. 02 Observe

    Robots-aware public HTML and bounded Git transport collect allowed evidence.

  3. 03 Preserve

    Append-only snapshots retain timestamps, confidence, parsers, and source hashes.

  4. 04 Explain

    Versioned formulas calculate ranks and persist one reason per score dimension.
